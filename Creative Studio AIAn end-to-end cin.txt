Creative Studio AIAn end-to-end cinematic AI video and image generation platform. Creative Studio AI integrates a Python FastAPI backend connected to ComfyUI with open-weights models (FLUX.1-schnell for image generation and LTX-Video for cinematic video rendering), paired with a React Native / Expo cross-platform mobile frontend.📁 Repository Structurecreative-studio-ai/

🚀 Quick Start1. Backend SetupPrerequisites: Python 3.10+, FFmpeg, and a running instance of ComfyUI.# Navigate to backend directory
cd backend

# Copy environment template and update values
cp .env.example .env

# Install dependencies
pip install -r requirements.txt

# Run the API server
uvicorn main:app --reload --host 0.0.0.0 --port 8000
2. Mobile Client SetupPrerequisites: Node.js 18+ and Expo CLI.# Navigate to mobile directory
cd mobile

# Install dependencies
npm install

# Start Expo development server
npx expo start

Prompt Crafting: User enters a scene description in the mobile app.Prompt Optimization: cinematic_prompt.py formats the prompt for optimal cinematic rendering.Inference: FastAPI sends workflows to ComfyUI for FLUX.1-schnell image generation or LTX-Video generation.Post-Processing: FFmpeg stitches or encodes clips into lightweight MP4/H.264 formats.Delivery: The mobile app streams or downloads the rendered video.🛡️ License & ComplianceSoftware Code: Licensed under the MIT License.AI Model Licenses:FLUX.1-schnell: Apache 2.0 / Black Forest Labs Open Weights.LTX-Video: Lightricks Community Open-Weights License.FFmpeg: Uses FFmpeg under LGPL v2.1+.Refer to NOTICE and COMPLIANCE.md for full attribution details.
